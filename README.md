# Contoso Travel

## Po co ten projekt
Contoso Travel pomaga planować wycieczki po Europie. Szukamy kierunków, cen i opinii w jednym miejscu.
## Jak zacząć
- Załóż konto na stronie
- Wybierz kierunek z listy
- Zarezerwuj termin
